# Plan Review Checklist

Use this as an inline self-review checklist. If the user explicitly asks for a separate reviewer mechanism and one is available, the same checklist can be delegated.

## What To Check

| Category | Question |
|---|---|
| Completeness | Are there placeholders, missing tasks, or vague steps? |
| Spec alignment | Does every acceptance criterion map to a task? |
| Task boundaries | Can each task be implemented and verified independently? |
| Buildability | Could a future Codex session execute this without chat memory? |
| Verification | Are commands or manual checks realistic and specific? |

## Output

```markdown
## Plan Review

**Status:** Approved | Issues Found

**Issues:**
- [Task or section]: [specific issue] - [why it matters]

**Recommendations:**
- [advisory only]
```
