# ECC Continuous Learning v2 Adaptation

This kit adapts these ECC continuous-learning-v2 concepts:

- Atomic instincts: one trigger, one action, one evidence trail.
- Confidence scoring: 0.3, 0.5, 0.7, 0.9.
- Scope isolation: project by default; global only after repeated evidence or user approval.
- Quality gate: Save, Improve then Save, Absorb into Existing, or Drop.
- Maintenance: status, validation, pruning, retirement, and promotion candidates.

This kit intentionally does not copy:

- Non-Codex storage paths from the upstream runtime.
- Background observer agents.
- PreToolUse/PostToolUse observation of every tool call.
- Automatic writing to global memory outside the project.

Reason: Codex project governance should prevent noisy memory. Learning is curated by default and can use raw observations only when useful.
